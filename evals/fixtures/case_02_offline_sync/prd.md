# 自然拼读课程离线学习与进度同步需求（v1.6）

## 业务背景
学生端 Android 平板支持弱网与断网场景下完成自然拼读单元练习，本地使用 Room 缓存练习记录与单元状态，待网络恢复后与服务端同步学习进度。

## 状态流转
单元状态包含：未开始 -> 学习中 -> 离线完成 -> 待同步 -> 已同步。

## 核心规则
1. 离线期间产生的新学习进度写入本地 Room 并标记待上传；恢复联网拉取服务端状态时，严禁使用较旧的服务端记录覆盖本地更新的进度。
2. 练习批次提交接口与本地 UseCase 必须校验明细非空，空练习批次必须拒绝提交，不得返回成功。
3. 选课弹窗中的单元完成进度标签需根据当前课程包的实际总单元数动态计算。
